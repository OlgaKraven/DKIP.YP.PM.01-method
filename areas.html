Вариант 01 · Магазин акварельных материалов

  1. Скачать стенд своего варианта

    Скачать только v01.zip: https://olgakraven.github.io/DKIP.YP.PM.01-method/downloads/v01.zip. Для оболочки использовать отдельный starter.zip из методички. Сохранить catalog.json и expected.csv этой области; архивы других вариантов не нужны.

  2. Собственная работа

    Разработать приложение организации «Тон». Предметная область: магазин акварельных материалов. Исполнения и фасовки каждого товара указаны ниже и в stocks[].label. Использовать data/v01/catalog.json из архива v01.zip. Образец «Линия» показывает способ, его товары и цены не переносить.

  3. Исходные товары

    V01-01 — Краска «Лазурь», 1100.00 руб., исполнения 10 мл / 20 мл, остатки 2 + 4; V01-02 — Бумага «Этюд», 1300.00 руб., исполнения 25 листов / 50 листов, остатки 2 + 3; V01-03 — Кисть «Линия», 1200.00 руб., исполнения № 2 / № 4, остатки 1 + 3; V01-04 — Ластик «Свет», 10.02 руб., исполнения малая / большая, остатки 1 + 2.

  4. 1. Подготовить данные

    Распаковать starter.zip в собственную папку. Заменить app/Data/catalog.json файлом v01.zip. В JSON найти коды V01-01…V01-04, четыре строки истории и controlDate=2027-01-15. Если собственная рабочая копия уже подготовлена, проверить её совпадение с этим набором, не начинать второй проект.

  5. 2. Реализовать модуль

    По этапам 3.3–3.7 методических рекомендаций реализовать PreviousMonth, Calculate, StockSummary и CreateCard в своём Pricing.cs. Правила общие: скидка 25% при отсутствии заказов в предыдущем месяце; остатки суммируются по исполнениям; «много» при >5, подсветка при ≤3. Не менять формулу скидки или пороги в зависимости от номера варианта.

  6. 3. Проверить собственные значения

    На 15.01.2027: V01-01 — 1100.00 руб.; V01-02 — 975.00 руб.; V01-03 — 900.00 руб.; V01-04 — 7,52 руб. Общие остатки: 6, 5, 4, 3; только последняя карточка подсвечена. Объяснить результат датами истории, а не номером товара.

  7. 4. Проверить переход и отказ

    На 01.02.2027 V01-01 получает скидку, V01-02 имеет базовую цену. Выполнить високосный, пустой и ошибочный сценарии этапа 3.9. Вернуть исходный файл и дату. Проверить повторный расчёт без накопления скидки.

  8. 5. Сохранить доказательства

    Сохранить словарь полей этой области, схему алгоритма, заполненную таблицу испытаний, снимки собственного окна и проект. В отчёте указать номер области и доступную ссылку на репозиторий. Отдельный обязательный проект образца не сдавать.
